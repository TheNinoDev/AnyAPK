Run Android APKs natively on Windows.

AnyAPK is a portable Windows app that runs Android APKs directly, without an emulator. A built-in DEX interpreter maps android.* calls to Windows, and anything that is not supported yet is collected into a ready-to-paste Discord report.

⚙

No emulator

APKs run through a native DEX interpreter. No VM, no Android image, no heavy setup.

🔌

Hot-swappable runtime

The engine is a separate, replaceable component. Update the runtime without rebuilding the app.

📝

Actionable reports

Unsupported hooks become a copy-paste-ready report for Discord, so gaps are easy to file.

🔒

Portable

Single Windows executable. Extracts its own payload and cleans up after itself.

🌐

Tunneling

Per-app and global WireGuard tunneling with direct, tunnel, and offline network modes.

⚡

Fast iteration

App and runtime versions are tracked separately, with independent releases.
